# Security policy

This repository is a small public portfolio demo and has no authenticated or write API. Please avoid filing reports that depend only on replacing the fictional local seed data or on features the project does not claim to provide.

Security-relevant design choices include parameterized SQL, tokenized FTS input, safe DOM rendering, bounded API parameters, loopback binding by default, and restrictive browser response headers.

If this project is published and a vulnerability is discovered, report it privately through the repository owner's preferred GitHub security contact rather than including exploit details in a public issue.
